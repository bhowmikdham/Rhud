# Rhud UX Audit

A full-surface UX/UI audit of the Rhud web app, Outlook add-in, and client-facing flows — covering navigation, forms, error/empty/loading states, and journey completeness across the product.

> Produced by a 13-lane audit workflow with adversarial verification (run `wf_f5aebac1-986`). Each audit lane independently inspected one journey/surface; an adversarial verifier then re-checked every finding against the live source to confirm it is real and to assess fix safety.

*Generated: 2026-05-31 from the cached workflow journal. **Updated 2026-05-31** — 3 safe journey-blocker fixes were applied (see "Fixes applied") and verified with a clean `pnpm --filter @rhud/web typecheck`; the 3 lanes the original run could not read (Outlook add-in, opportunity-detail, gathering templates) were re-audited (see "Re-audit addendum" at the end). The re-audit supersedes the four placeholder rows in the tables below ("AUDIT BLOCKED…", "Audit could not run…", "Templates lane not audited…", and the related auth blocker).*

## Fixes applied (2026-05-31)

These verified journey-blockers were fixed directly. Working tree only — not yet committed.

| Finding | File | Change |
|---|---|---|
| Clipboard copy on the share screen silently fails while claiming "Copied" | `apps/web/src/app/opportunities/new/page.tsx` | `copy()`/`copyMessage()` now await the write in try/catch, only flip to "Copied" on success, show a `role="alert"` "copy manually" message on failure, and the token URL is `user-select: all`. |
| Failed file uploads strand the rep with no remove/retry path | `apps/web/src/app/opportunities/new/direct-ingest-form.tsx` | Each artifact row gets a Remove (✕) button; failed rows get a Retry that re-uploads the original `File` in place. |
| Add-in sign-in forces re-login when the user is already signed in | `apps/web/src/app/login/page.tsx` | The addin-flow effect now reuses the stored `rhud.token` and redirects to the add-in callback instead of doing nothing. |

**Not applied — needs backend work (was mis-classified as file-local):** "Files stuck in pending/processing/retry_queued have no terminal escape." There is no user-facing extraction-skip endpoint (`markSkipped` is internal only), so a "Skip file" control needs a new API route + service + client method first. Tracked as cross-file.
